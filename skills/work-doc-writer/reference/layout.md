# 版式与源稿语法

参数取自 2026 年新版手册（监管网自动录入、电网管理平台、电网物资技术资料处理工具）。`scripts/build_docx.py` 已内置，这里供核对和手工调整时查阅。

## 1. 版式参数

| 项 | 操作手册 / 说明书（manual / spec） | 成果报告（report） |
|---|---|---|
| 纸张 | A4 纵向 | A4 纵向 |
| 页边距 | 上下 2.54 cm，左右 3.17 cm | 上下 2.6 cm，左 2.8 cm，右 2.6 cm |
| 封面 | 工具名 + 文档类型（方正小标宋简体二号，居中）+ 日期/版本表 | 无封面，首页标题方正小标宋简体二号居中 |
| 目录 | 有，自动目录，收录 1–3 级标题 | 无 |
| 页码 | 无 | 页脚居中“— 1 —” |
| 正文 | 仿宋_GB2312 三号（16pt），首行缩进 2 字，固定行距 28 磅，段前段后 0 | 同左 |
| 一级标题 | 黑体三号，自动编号“一、” | 同左 |
| 二级标题 | 楷体三号，自动编号“（一）” | 同左 |
| 三级标题 | 仿宋三号加粗，首行缩进 2 字，自动编号“1．” | 同左 |
| 四级标题（操作步骤） | 仿宋三号，首行缩进 2 字，自动编号“（1）” | 同左 |
| 图片 | 居中，宽度不超过 14.5 cm，高度不超过 20 cm，单倍行距 | 宽度不超过 15.5 cm |
| 图题 | 图下方，仿宋_GB2312 五号居中，“图1-1 ××展示图” | 图下方，“图1 ××” |
| 表格 | 网格线，居中，仿宋_GB2312 小四，表头加粗 | 同左；表题在表上方“表1 ××” |

注意：图片段落必须单倍行距。固定行距 28 磅会把图片裁成一条。

## 2. 源稿语法（Markdown 子集）

源稿是一份 `.md`，开头是 YAML 文件头，正文**一行一段**。

```markdown
---
profile: manual            # manual 操作手册 / spec 说明书 / report 成果报告
title: 电网管理平台多场景自动化处理机器人   # 多行标题写成列表
doc_type: 操作手册          # 封面第二行；省略时按 profile 取默认
versions:                  # report 可省略
  - date: 2026.04.02
    version: V1.0
---

# 功能介绍
本工具提供 3 个功能，包括如下：
1、打包功能：用于……

# 操作说明
## 打包功能
### 准备数据
1. 如果选择“定点打包”，准备对应的 Excel 文件。
### 操作步骤
1. 双击“main.exe”启动程序。
2. 在“运行模式”中选择“打包”。
![图1-1 打包功能操作界面图](shots/annotated/1-1.png)
### 结果说明
系统会按照所选打包模式完成数据处理，并在日志中输出执行结果。
```

| 写法 | 生成效果 |
|---|---|
| `#` / `##` / `###` | 一 / 二 / 三级标题，自动编号 |
| `1. 文字` | 四级标题，自动编号“（1）”（这是原手册的操作步骤写法） |
| `# 摘要 {-}` | 不编号、居中的标题（摘要、附件清单等） |
| `![图题](路径)` | 居中图片 + 图下方图题；路径相对源稿 |
| `表1 标题` 紧跟 `\| 表格 \|` | 表上方表题 + 表格 |
| `\| a \| b \|` | 表格，第一行是表头 |
| `**文字**` | 加粗 |
| `- 文字` | 普通段落（原手册不用项目符号，列举写“1、”“2、”） |
| `<!-- pagebreak -->` | 分页 |
| `<!-- 备注 -->` | 忽略 |

功能清单“1、打包功能：……”用顿号，不会被识别为步骤。

## 3. 生成与更新目录

- `build_docx.py` 生成 docx 时目录只是一个域，需要 `--finalize`（调用本机 Word，没有 Word 时用 WPS）刷新后才有内容。
- 两者都没有时，提醒用户在 Word 里右键目录 → 更新域。

## 4. 已有模板时

用户给了单位模板 docx 时，以模板为准：先按模板生成内容，再把版式参数对照本页逐项核对，差异告诉用户，不擅自改模板。
