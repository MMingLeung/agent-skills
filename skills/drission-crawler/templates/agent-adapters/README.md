# Agent 适配入口模板

主规则安装位置（本机）：

- Cursor：`~/.cursor/skills/drission-crawler/`
- Codex：`~/.codex/skills/drission-crawler/`

- Codex：活动技能目录自动发现 `SKILL.md`。
- Cursor：个人技能目录自动发现；也可复制 `cursor-drission-crawler.mdc` 到项目 `.cursor/rules/`。
- 通用 Agent：将 `AGENTS-drission-crawler.md` 合并到项目 `AGENTS.md`，不要复制完整规则正文。
