# 探针稳态法（跨站可复用）

适用：任意站点上「先摸清再固化」的自动化——录制/猜测 locator 不稳、点了没数据、截到空壳、SPA 填了不搜。  
站点具体选择器仍放 `sites/<站点>/`；本文只固化**怎么试、怎么定、怎么等**。

## 核心一句话

```text
录制只当线索 → 探针对比「空态 vs 就绪态」 → 语义步骤 + 稳定 locator + 业务就绪信号
→ 连续稳态后再截图/入库；不要盲回放坐标、nth、动态 id、固定 sleep
```

## 1. 录制 / 人工操作 → 意图，不抄死 locator

从录制或口述里只抽取：

| 抽什么 | 例子 |
| --- | --- |
| 入口 URL / 路由形态 | hash 路由、列表页 vs 详情页 |
| 业务动作链 | 搜 → 点列表一类 → 详情切类 → 截 |
| 触发方式线索 | 点图标？回车？点「查询」按钮？ |
| 成功时人眼看到什么 | 列表变少、标题出现、表有行、`共 N 条` |

禁止把录制里的动态 id、`nth-of-type(4)`、绝对 xpath、像素坐标当生产 locator。

## 2. 探针三轮：对照空态，不要一次截完就信

对「关键动作之后」做短轮询采样（如 0.3～0.5s × 十余次），每次记同一组信号：

```text
url / title
body 可见文本长度（innerText，不是整页 HTML）
业务关键字是否出现（项目名、表头、主键字段）
计数文案是否从「0 / 空」变为「≥1 / 有数据」
表格行数或关键字段是否出现
```

对比：

| 阶段 | 典型表现 | 结论 |
| --- | --- | --- |
| 空壳 / 过渡 | 短正文、计数为 0、有壳无字段、旧页残留 | **禁止截图/入库** |
| 就绪 | 目标业务字段出现 + 计数/表行合理 | 可进入稳态判定 |
| 假就绪 | 仅导航高亮、仅附件区、仅上一 TAB 残留 | 继续等或改触发 |

探针脚本只负责**打印信号时间线**；用时间线决定生产里的就绪谓词，不要用「探针碰巧 sleep 够了」当规则。

## 3. Locator 优先级（跨站）

按稳到不稳排序：

1. 语义属性：`placeholder`、可见精确文案、`aria-*`、稳定 `data-*`
2. 作用域内结构：`列表容器 > 行`，再用**行内文本包含业务关键字**筛选
3. 稳定 class 组合（经探针证明不随构建变）
4. 最后才考虑 xpath / 序号

硬禁止当默认：

- 构建期动态 id（如 `el-id-数字`）
- `nth-of-type(N)` / 录制绝对 xpath
- 整页模糊点第一个「搜索」类节点（易点错头部装饰图标）

输入框旁的真实触发控件：在**同一输入组件包裹层**内找后缀图标/按钮（探针 DOM 邻域），不要猜全局放大镜。

## 4. SPA 填值与触发（Vue / React / Element 类）

```text
定位输入框（稳 locator）
→ 原生 value setter（或框架认可的写入）+ input/change（必要时）
→ 回读：模型侧或列表侧是否变化
→ 用探针确认的触发器提交（按钮 / 后缀图标 / 明确查询）
→ 后置条件看「列表/结果变了」，不看「框里有字」
```

常见坑：

- `ele.input` 或只改 DOM `value` → 框里有字但列表未过滤  
- 以为 Enter 能搜 → 站点实际只认图标/按钮点击  
- 回读 `attr('value')` 为空但搜索已生效 → 以后置业务信号为准，不单靠 attr

## 5. 列表与详情：语义点选，不点第 N 条

```text
等列表容器出现
→ 收集行文本
→ 选「含项目名 + 含目标类型文案」且排除澄清/无关
→ 点击该行
→ 后置：新 TAB 或 URL/路由进入详情形态
```

多 TAB：按 URL 子串 / 详情特征找 tab，禁止默认「最后一个 tab 就是详情」。

## 6. 切类 / 切 TAB 后的就绪（类型专属）

每换一类内容，单独定义就绪，不要共用「页已打开」：

```text
动作前记录 url + bodyLen 签名
→ 点击目标类文案
→ 等：url 变 或 正文签名变
→ 等：本类型专属字段出现（表头/主键/「共 N 条」N≥1）
→ bodyLen（或关键区签名）连续两次 poll 相同 → 稳态
→ 才截图 / 抽数
```

拒绝信号示例（通称「空壳」）：计数为 0、业务表全空、只有导航无正文、上一类附件残留冒充本类。

## 7. 截图 / 入库门禁

与 [ready-signals.md](ready-signals.md) 层 3 一致，并加两条硬门：

1. **专属就绪谓词为真**（本类型字段，不是「任意有字」）  
2. **连续稳态**（至少 2 次 poll 签名不变）  
3. 可选：文件体积下限作废片兜底（不能代替 1、2）

缩放、滚动后再采一次就绪，再截（缩放可能触发重排空帧）。

## 8. 固化进代码的顺序

```text
1. 探针得到「空态→就绪」时间线与触发器
2. 写成语义函数（搜/点/等/截），locator 用稳属性
3. 就绪谓词写进 poll，禁止长 sleep 顶替
4. 失败分类：无搜索框 / 列表未过滤 / 详情空壳 / 切类未变 / 稳态超时
5. 站点差异进 sites/<站点>/；本文件方法不改
```
