# 政务 GUI 参考细则

主决策与门禁见 [SKILL.md](SKILL.md)；完整 token 见 [tokens.md](tokens.md)。

## GUI 文案细则

### 推荐

- `请输入项目名称`
- `请选择日期`
- `保存成功`
- `上传失败，请重试`
- `暂无数据`
- `未查询到结果`
- `确认删除？`
- `最多上传 10 个文件`
- `仅支持 PDF、DOCX`
- `数据已更新`
- `处理中…`

### 避免

- `请您在此处输入需要查询的项目名称信息`
- `恭喜您，您的数据已经成功保存完成`
- `温馨提示：请认真检查您所填写的所有内容是否准确无误`
- `当前暂时没有可以向您展示的数据内容`
- `您是否确认要执行删除当前这条数据的操作？`

### 按钮文案

优先：查询、重置、新增、保存、提交、导入、导出、下载、上传、编辑、删除、返回、关闭、确认、取消、查看、办理、审核、通过、退回。

避免：点击查询、立即开始查询、保存当前信息、确认并继续下一步、点击这里查看更多。

除非业务确有歧义，按钮通常 **2–4 个汉字**。

### 弹窗确认

优先：`确认删除该记录？`

若不可恢复重要：`删除后不可恢复，确认删除？`

避免：`请确认您是否真的需要删除当前所选择的这条记录，删除后可能无法恢复。`

## 排版

中文默认：`Microsoft YaHei` → `PingFang SC` → `Noto Sans CJK SC` → `Source Han Sans SC` → system sans-serif

| 场景 | 字号 | 字重 |
|------|-----:|-----:|
| 页面主标题 | 20–24px | 600 |
| 区块标题 | 16–18px | 600 |
| 表单 / 表格正文 | 14px | 400 |
| 辅助信息 | 12–13px | 400 |
| 按钮 | 14px | 500 |

原则：

- 避免 32px 以上大标题占业务页
- 正文优先 14px；同一页字号档位通常 4–5 档
- 不要每个区域都加标题
- 数字型核心指标可略放大，保持克制

## 布局与组件

### 页面结构

桌面：`顶部栏 + 左侧导航 + 主内容区`

主内容区典型顺序：

1. 面包屑 / 页面标题
2. 查询条件
3. 操作工具栏
4. 表格 / 表单 / 业务内容
5. 分页或操作区

不要把每一块都套成独立大卡片。桌面优先用满横向空间，避免内容挤在正中形成大面积空白。

### 查询区

- 简单查询：单行
- 条件较多：两到四列栅格
- 非核心：放入「更多条件」
- 按钮在条件末端或右侧：`查询` / `重置`
- 不加查询区大段说明

### 表单

- 标签简短；必填用 `*` 或统一标识
- 帮助文字仅在确有规则时出现
- 错误紧邻字段
- 长表单按业务分组，不按视觉过度拆卡
- 同组控件高度一致，默认 36px

### 表格

- 表头浅灰；表头字重 500–600；行高约 40px
- 关键字段可固定列；操作列右侧
- 数值右对齐；状态居中或按业务统一
- 超长文本省略，支持悬浮或进详情
- 不使用明显斑马纹；Hover 极浅蓝（如 `#F4F8FE`）

### Button

主按钮：背景 `#0A4CB5`、白字、高 36px、圆角 4px、字号 14 / 字重 500。

次按钮：白底、蓝色或深灰字、1px 边框、4px 圆角。

同区通常只保留一个主按钮。

### Input / Select

- 高 36px、圆角 4px
- 默认边框 `#D8DEE8`；Focus `#0A4CB5`
- Placeholder 灰色
- 无厚重内阴影；不用胶囊输入框

### Card

- 白底、1px 浅灰边框、6px 圆角、内边距 16px
- 默认无阴影或极轻阴影
- 能用分隔线/浅底分区时，不增加卡片层级

### Tabs

- 默认深灰字；当前项 `#0A4CB5` + 底边 2px 蓝线
- 大面积胶囊 Tab 仅用于小型筛选器

### Modal

- 圆角 6px；标题 16–18px / 600；正文 14px
- 底部按钮靠右；主动作 `#0A4CB5`
- 提示尽量一句话

### Status

短标签：待提交、待审核、审核中、已通过、已退回、已完成、已作废、已关闭。

轻背景 + 深色文字；不用高饱和实心大面积填充。

### Empty State

- 默认：`暂无数据`
- 查询无结果：`未查询到结果`
- 避免：`这里空空如也`、`暂时还没有任何内容哦`

## Icons

- 线性、简洁、统一；常规 16 / 18 / 20px
- 主操作图标可用 `#0A4CB5`；普通工具图标深灰
- 不依赖彩色图标表达层级
- 不用卡通、手绘、拟物图标
- 图标旁已有文字时，不加额外解释

---

## Feedback

| 类型 | 优先文案 |
|------|----------|
| Success | `保存成功` / `提交成功` / `导入完成` |
| Error | `保存失败，请重试` / `文件格式不支持` / `网络异常，请重试` |
| Loading | `加载中…` / `处理中…` / `正在导入…` |

错误说明问题即可，不一次抛技术堆栈或大段后台异常。Loading 不用连续变长句。

## Responsive Behavior

| 设备 | 建议 |
|------|------|
| Mobile | 单列；表格改列表或横向滚动；主操作易触达 |
| Tablet | 查询区 2 列；表格保留主要字段 |
| Desktop | 查询区 2–4 列；完整表格与侧边导航 |
| Wide | 内容可扩展，避免无限拉宽正文/表单 |

优先保证 1366 / 1440 / 1920 宽度可用。

---

## Accessibility

- 正文与背景足够对比度
- 不只靠颜色表达成功/错误/选中
- 输入框有明确 Focus；禁用态可区分
- 表单错误有文字说明
- 点击目标建议 ≥32px，高频操作优先 36–40px
- 键盘场景保留清晰焦点

---

## 默认颜色适用范围（补充）

主色适用于：主按钮、当前菜单、当前 Tab、选中、焦点边框、主链接、关键图标、进度条主色、单序列图表、主要强调数字。

不适用于：成功（绿）、警告（橙）、错误/删除（红）、禁用（灰或低饱和蓝灰）。
