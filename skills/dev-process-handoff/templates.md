# CURRENT_HANDOFF 模板

按项目已有结构增补；若新建，用下列骨架（可删无关节）。

```markdown
# CURRENT_HANDOFF

## 状态
- 日期：
- 范围：（功能 / 模块）
- 结论：进行中 | 可交接 | 阻塞

## 本轮关键变更
- …

## 单一事实来源
- 专题 / 代码路径：
- 与旧全文文档关系：（若有“勿再当默认真相”的旧大文档，在此标明）

## 验收口径
- 必须通过：
- 明确不做 / 禁止：

## 验证记录
| 类型 | 范围 | 结果 | 备注 |
|------|------|------|------|
| 静态检查 | | | 不得称为 live |
| 定向测试 | | | |
| live 回读 | | | 仅真实执行过才勾 |

## 未决 / 下一步
- …
```

## 专题文档更新要点

- 只改正文里被本轮改动击中的约定（locator、默认值、步骤、门禁）。
- 不把聊天过程流水账贴进专题；handoff 写摘要，专题写可执行事实。
- 新增专题时，在索引（如 `00_index.md`）补路由条目。
