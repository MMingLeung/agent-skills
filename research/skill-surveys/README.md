# 外部技能阅读笔记

本目录记录对 GitHub 上公开 Agent Skills 的阅读，供对照本仓库技能写法。这里的材料不是可安装技能，不进入 `skills/`，也不作为交付 SOP。

约定：

- 按日建目录 `YYYY-MM-DD/`。
- 每个被读仓库一篇笔记，文件名用仓库简称。
- 同日另写 `synthesis.md`，汇总写法、设计意图，以及对本库交付型技能可参考与不宜搬入的地方。
- 跨日仍然成立的判断写在仓库根下的 [`research/insights.md`](../insights.md)，单日细节不重复堆进该文件。
- 星标取笔记所写日期的 GitHub API `stargazers_count`。数字会变，不回写历史。
- 专有或未明确开源的正文不摘录步骤、脚本和长段原文。
