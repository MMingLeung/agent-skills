# 花叔设计 huashu-design

查阅日：2026-10-26。

## 1. 来源

- 仓库：<https://github.com/alchaincyf/huashu-design>
- 默认分支是 `master`。`main` 上没有 README 和 SKILL.md，查阅时以 `master` 为准。
- 星标：26461（当日 GitHub API `stargazers_count`）
- 许可：MIT（仓库 SPDX 与仓库内 `LICENSE`）
- 仓库简介中的能力范围包括网页、App 原型、可编辑 PPTX、动画、信息图，以及带样张的风格库。具体风格数量以仓库当时简介为准，本笔记不抄风格清单。

## 2. 它是什么

这是一个用 HTML 做视觉交付的技能：交互原型、幻灯片、信息图、动画和视频，并带评审。frontmatter 写明生产级 Web 应用、需要后端的系统不走本技能。

新设计一律先出三个方向给使用人选择，即使用人已经指定风格或品牌也不跳过。选定之后才进入制作。纯导出、改字、修缺陷等机械操作走交付链，不过这道选择门。

## 3. 写法特点

- `SKILL.md` 先规定身份和适用范围，再写每个任务开头的三件事：读该用户以往偏好、看最近交付以免重复、核对本机有哪些能力。三件事失败不阻塞，脚本找不到就检查路径。
- 路由表按任务指向不同手册：网页、幻灯片、信息图、App 原型、动画、评审各有文件；多个信号同时出现就叠加。手册只写该模块特有的内容，共用规则留在入口的「窄桥」。
- 窄桥是短的硬步骤：先核对事实，再从已有材料出发，品牌资产按协议处理，三个方向必经，素材按能力分档，装饰和内容分开，检查点必须落成文件。文件不在就视为该环节没做。
- 「开阔地」与窄桥分开，标明是参考而不是配额，避免模型把参考例子当成每单必做清单。
- 收工另有三件事。弱运行环境一节要求 references 只读当前模块，不一次读完全库。
- 仓库有 `references/`（流程、评审、版式、导出）、`scripts/`（偏好、体检、能力探测、导出和校验）和 `test-prompts.json`。入口不把这些脚本的参数展开成教程。

## 4. 原理与设计意图

视觉任务如果只给一句「做得好看」，模型会直接出一版默认页面。三个方向是为了把审美选择交还使用人，并且防止「用户说了风格」被当成可以跳过方案比较。

检查点落成文件，是为了让后续步骤有可核验的输入，而不是靠对话里说「已经想过了」。开工脚本把个人偏好和近期重复样式显式读出来，是为了跨项目记住教训，同时用「只适用于某类物料」限制偏好外溢。

路由加窄桥把「共用纪律」和「模块技巧」拆开。技巧文件会很长（动画、导出、镜头），若每次都读，上下文会被占满，窄桥反而执行不了。

## 5. 对照本库

本库的界面技能是 `government-service-design`：白底浅灰、表单表格、主色约定、短按钮文案。花叔设计服务的是展示型视觉稿。二者可以对照写法，不能对照审美。

### 可借鉴

- `government-service-design` 已把色值放在 `tokens.md`、组件文案放在 `reference.md`。保持 `SKILL.md` 只留硬规则和「何时用 / 不用」，按任务打开对应节，不要在一次对话里通读全部参考。
- 「文件不在就视为没做」可用于 `dev-review-verify` 和 `drission-crawler`：LIVE 记录、探针报告以磁盘上的产物为准。对话里说已核对，不能代替打开文件。
- 「机械修改不过方案门」可以用来约束开工卡：只改错别字、只补一个已确认字段时，不重新把整卡问一轮。范围变化、新增禁止项时仍要改卡。
- 偏好和外溢这一条对本库的意义是：某项目配方卡里的路径和命令只用于该项目，不写成所有仓库的默认。`dev-review-verify` 已规定本机索引不入库，继续维持。

### 不要照搬

- 不把三方向视觉方案、风格库、动效成片、品牌展览页流程写进 `government-service-design`。未指定颜色时仍用已定主色；已指定则跟指定值。不每单出三套外观。
- 不把该技能用于政务后台的表单、表格、查询和办理页。营销页、作品集本来就在 `government-service-design` 的不用范围内。
- 不把 HTML 转 PPTX、视频导出脚本引进 `work-doc-writer`。工作文档仍是对照源码写 Word，版式走本库模板。
- 不把 `learn.py` 一类跨项目外观账本放进公开仓库。其中容易混入本机项目和偏好，与「不提交本机验收索引」的约定冲突。

## 6. 一句话建议

学习「共用规则短、模块手册按需读、检查点必须落文件」；政务界面继续单套克制规范，不引入三方向视觉门。
